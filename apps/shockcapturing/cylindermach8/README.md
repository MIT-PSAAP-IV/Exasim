# Exasim Text2Code Export

This directory contains the Mach-8 cylinder shock-capturing application exported
from `examples/ShockCapturing/cylindermach8/pdeapp.m`. The PDE and application
text files are generated by MATLAB's `exporttext2code`; they are not maintained
as an independent transcription of the frontend model.

Generated files:

- `pdemodel.txt`: PDE model definition consumed by Text2Code.
- `pdeapp.txt`: application, mesh, solver, output, and runtime configuration.
- `grid.bin`: mesh coordinates and connectivity.
- `xdg.bin`, `udg.bin`, `vdg.bin`, `wdg.bin`: optional field data written only when present.
- `materialdatabase.bin`: optional material-property database packaged when `pde.materialdatabase` is specified.

Regenerate the application with:

```sh
cd examples/ShockCapturing/cylindermach8
matlab -batch "run('export_text2code.m')"
cd ../../../apps/shockcapturing/cylindermach8
/path/to/exasim-prefix/bin/text2code pdeapp.txt --out-dir "$PWD" --gen-only
```

The `vdg.bin` file stores external variables. In backend data structures these are also called `odg`.

Configure, build, and run the generated header-provider application with:

```sh
cmake -S . -B build -DExasim_DIR=/path/to/exasim-prefix/lib/cmake/Exasim
cmake --build build -j
./build/exasimapp pdeapp.txt | tee text2code_run.log
```

With `saveParaview = 1`, the AV-continuation completion path writes
`dataout/outvis.vtu`. Exasim's established VTK names are positional:

- `Scalar Field 0`: Mach number, identical to MATLAB `eulereval(sol,'M',gam,Minf)`;
- `Scalar Field 1`: plotted AV, `physicsparam(end)*vdg(:,2,:).*tanh(physicsparam(end-2)*vdg(:,1,:))`.

After running the MATLAB reference and this application, reproduce the numerical
comparison with:

```sh
python3 verify_against_matlab.py
```

The verifier compares DG conservative and derived fields, reproduces Exasim's
DG-to-CG averaging for the VTK point fields, and checks the printed nonlinear and
GMRES histories. It writes `verification_results.json`.
