# Coupled Poisson: matching

Text2Code version of `examples/CoupledProblems/Poisson/matching`, exported from the
MATLAB example with `exporttext2code`. Two Poisson models on [0,0.5] x [0,1] and [0.5,1] x [0,1] (8 x 16 quadrilaterals each, p = 3) coupled through the matching interface x = 0.5. The exact solution is
u = sin(pi x) sin(pi y).

Files:

- `pdeapp1.txt`, `pdeapp2.txt`: application, mesh, solver and coupling settings of each model.
- `pdemodel1.txt`, `pdemodel2.txt`: PDE model definitions consumed by Text2Code.
- `grid1.bin`, `grid2.bin`: mesh coordinates and connectivity of each model.

Build against an installed Exasim and run the two-domain coupled solver:

```sh
cmake -S . -B build -DExasim_DIR=/path/to/exasim-prefix/lib/cmake/Exasim
cmake --build build
mpirun -np 7 build/exasimapp pdeapp1.txt 3 pdeapp2.txt 4
```

The run writes `datain1/`, `datain2/` (generated by Text2Code on first run) and
the solutions `dataout1/outudg_np*.bin`, `dataout2/outudg_np*.bin`.
