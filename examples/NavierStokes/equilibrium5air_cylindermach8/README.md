# Equilibrium five-species-air Mach-8 cylinder

The equilibrium-air thermodynamics are generated by the canonical Text2Code
application in `apps/meshadaptivity/cylindermach8_equichem`. Native Python and
Julia symbolic chemistry models do not currently exist, so `pdeapp.py` and
`pdeapp.jl` copy that immutable application, run `text2code`, and launch its
four-rank executable.

Set `EXASIM_PREFIX` to the installation prefix, then run either entry point.
Outputs are written under `python_run` or `julia_run` without modifying the
canonical app inputs.
