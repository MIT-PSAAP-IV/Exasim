# Two-Dimensional Linear-Elastic Beam

This example bends an `8 x 1` rectangular beam represented by a `64 x 8`
quadrilateral mesh. MATLAB, Python, and Julia use the same isotropic linear
stress law, boundary conditions, traction, third-order HDG discretization,
and solver settings.

Run `pdeapp.m`, `pdeapp.py`, or `pdeapp.jl` from this directory after
configuring the corresponding Exasim frontend.
