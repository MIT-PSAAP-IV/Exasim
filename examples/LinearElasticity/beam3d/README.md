# Three-Dimensional Linear-Elastic Beam

This example bends a `5 x 1 x 1` beam represented by a `20 x 4 x 4`
hexahedral mesh. MATLAB, Python, and Julia use the same isotropic linear stress
law, boundary conditions, traction, third-order HDG discretization, and solver
settings.

Run `pdeapp.m`, `pdeapp.py`, or `pdeapp.jl` from this directory after
configuring the corresponding Exasim frontend.
