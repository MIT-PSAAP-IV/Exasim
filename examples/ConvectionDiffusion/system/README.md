# Two-Component Convection-Diffusion System

This example solves a steady two-component convection-diffusion system on a
`32 x 32` quadrilateral mesh. The MATLAB, Python, and Julia drivers share the
same third-order discretization, source coupling, homogeneous boundary data,
and solver settings.

Run `pdeapp.m`, `pdeapp.py`, or `pdeapp.jl` from this directory after
configuring the corresponding Exasim frontend.
