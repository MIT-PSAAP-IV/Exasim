# Analytic-monitor square mesh

This case is the explicit-monitor variant of the density-equalizing square
example. Its Poisson and transport models evaluate the ring monitor directly
from the physical coordinates. MATLAB, Python, and Julia implementations are
provided; see the neighboring `square` case for the staged algorithm.

Run `pdeapp.m`, `python3 pdeapp.py`, or `julia pdeapp.jl` from this directory.
