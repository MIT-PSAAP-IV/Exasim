# Axisymmetric streamer Poisson problem

This case solves the electrostatic potential generated by a Gaussian streamer
charge distribution. All frontends read the tracked 16k-element Gmsh mesh,
normalize it identically, and apply the same four electrode/far-field boundary
conditions.

```bash
matlab -batch "run('pdeapp.m')"
python3 pdeapp.py
julia --project=../../../frontends/Julia/Exasim pdeapp.jl
```
